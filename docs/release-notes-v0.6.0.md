## PhoneMic v0.6.0

本次更新带来了手机端的"遥控面板"——除了语音输入，现在你还能用手机当无线鼠标、触摸板和快捷键键盘用；同时新增文件与图片传输，手机上的文件和照片可以直接传到电脑上。文字上屏也多了新选择：切到模拟键盘输入，在终端、SSH 客户端这类程序里一样能上屏。底层通信协议也做了升级，传输效率和安全性都有提升。

### 🖱️ 手机变电脑遥控器

v0.6.0 在手机端页面新增了**控制面板**，输入框为空时，右边的"发送"按钮会变成三横菜单按钮，点开就能展开工具面板。展开后，输入框上方会出现 4 个切换按钮：**触控板、摇杆、键盘、文件**，点击切换不同面板，默认停在触控板。

**触控板面板** — 类似笔记本触摸板：
- 绝对坐标映射，手指点哪光标去哪
- 轻点即点击，适合精确操作

**摇杆面板** — 手机当无线鼠标用：
- 手指在圆形区域内推动，电脑光标跟着移动，松开即停
- 支持左键、右键、中键点击，双击、长按拖拽也都能用
- 滚轮滑动翻页，浏览网页、看文档很方便

**键盘面板** — 常用快捷键一键触发：
- 撤销、全选、复制、粘贴、剪切、删除这些高频操作一键搞定
- 不用再在手机输入法里找组合键，按一下就等于电脑上按下了 Ctrl+Z / Alt+Tab 之类

> 控制面板可以随时收起，不影响语音输入的正常使用。

### 📁 文件直传到电脑

手机上的文件可以直接传到电脑里了，不用再发微信/QQ给自己：

- 在手机端点附件按钮，选择文件发送
- 电脑端自动保存到 **下载 → PhoneMic** 文件夹
- 文件名重复会自动加序号（`报告(1).pdf` 这样），不会覆盖
- 传大文件没问题，分块传送，稳定可靠
- 传输过程中可以随时取消（取消后不保留进度，需重传）

### 🖼️ 图片直接到剪贴板

看到手机上有意思的图，想直接粘到电脑的聊天框或文档里？现在可以一步到位：

- 手机端选择图片发送
- 电脑端自动写入系统剪贴板
- 你直接在微信、Word、画图、浏览器里 Ctrl+V 粘贴就行
- 不落盘、不留痕，用完即走

### ⌨️ 上屏方式随心切换

手机上的文字送到电脑光标处，现在有两种方式可选：**剪贴板粘贴**（默认，速度快、长文本一次到位）和**模拟键盘输入**（逐字符敲键，不占用剪贴板）。

在终端、SSH 客户端、vim 这类 Ctrl+V 不生效的程序里，切到模拟键盘输入，文字照样能落到光标处。

切换不用打开设置窗口，三个入口任选：

- 主界面菜单栏的 **上屏方式**
- 托盘图标右键菜单
- 设置窗口里的 **上屏方式**

三处是同一个开关，改一处其余地方立刻同步，并且**即时生效、无需重启**。当前选中的那种前面会标出圆点。

### 🛠 语音命令支持正则匹配

命令的匹配类型新增**正则匹配**：用正则表达式在你说的话里搜索（不区分大小写），还能用 `{0}`、`{1}` 把括号里捕获的内容嵌进动作参数，触发更灵活。比如匹配模式写 `^请帮我记录[:：,，\s]*(.*)`，动作参数写 `cmd /c echo {1} >> d:/todo.txt`，说“请帮我记录：买菜”就会把“买菜”追加到 d:/todo.txt。

### 🛠 底层改进

- 通信协议从 JSON 升级为 MessagePack，二进制传输更高效，传文件和图片时性能更好
- 端到端加密进一步优化：加密方式更简洁，防重放机制更严谨
- 整体代码结构更清晰，后续加新功能会更快
