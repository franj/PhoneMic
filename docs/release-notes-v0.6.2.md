## PhoneMic v0.6.2

这一版以修补为主，没有结构性的改动：手机端不再"假装在线"、页面打开更快、几个反复出现的小毛病都修掉了，另外带来一个社区贡献的**词典纠正**，以及重做后的**使用帮助**。单条都不大，但都是日常会碰上的。

### 📖 新增：词典纠正（自动改掉固定错字）

语音识别对某些词的错法是固定的——同一个词每次都听成同一个错字。现在可以维护一张"错 → 对"的替换表，**上屏前自动套用**，不用每次手动改。

入口两处：主界面菜单 **程序 → 词典配置**，或托盘右键 **词典配置**。

| 匹配类型 | 什么时候用 |
| --- | --- |
| **字面量替换**（默认） | 固定的错别字，出现几次改几次。绝大多数情况选这个 |
| **仅整句匹配** | 只有整句正好等于查找内容才替换，不会误伤正文 |
| **正则匹配** | 需要批量处理时用，例如删掉"嗯""呃"这类口头叹词 |

几条要点：

- 三种匹配类型**都不区分大小写**——手机今天给你 `console`、明天 `Console`，都算命中，上屏统一用你写的样子
- **「替换为」留空**表示把查找到的文字删掉，用来清口头禅
- 词条按列表顺序从上到下套用，前一条的结果会进入后一条；每行右侧 ▲▼ 调整顺序，左侧复选框可随时停用
- **词典先于语音命令生效**：被听错的「确定」只要纠正回来，v0.6.0 里配好的命令照样命中
- 改完**立即生效**，不用重启

> 悬浮窗里显示的是识别原文，纠正发生在文字上屏那一刻——所以预览里可能短暂看到错字，落下去的时候已经是改好的了。

感谢 [@Sillykjs](https://github.com/Sillykjs) 贡献这个功能。

### 📚 使用帮助重做：带目录和搜索的说明书

以前点「使用帮助」是把 `USER_GUIDE.md` 交给记事本打开，`##`、`**` 和表格竖线原样摊着，等于让用户读源码。现在改成应用内窗口：左目录右正文，表格有框线、标题分层级；窗口独立不压住主界面，看的时候随时能切回去操作。

- **目录现场从标题生成**（h1~h3），以后文档增删章节程序不用改；点目录滚到章节，正文里「详见 2.7」这类跳转也能直接点，反过来滚动正文时目录会高亮当前一节
- **搜索**：输入即过滤左侧目录，`Enter` / `↓` 逐处往下、`Shift+Enter` / `↑` 往回翻，命中全部淡黄高亮并显示「3/70」，到末尾绕回开头，`Ctrl+F` 聚焦搜索框
- 说明书补了**英文、台湾繁体、香港繁体**三份，跟随界面语言自动切换

之所以是「输入过滤目录 + 回车查正文」两段式，而不是边输入边跳正文：中文里一个常用字就能命中几百处，光标乱跳比不搜更糟。

### ⚡ 手机页面打开更快

加密库从 libsodium.js 换成了纯 JS 的 noble 构建。以前扫码后要先拉一份 322KB（gzip）的 WASM 产物、再等它初始化；现在整份 `sodium.js` 约 62KB，没有 WASM 这一步，页面出得更快。

对外接口完全照 libsodium 实现，手机端与 PC 端的调用代码一行没改，通信协议、加密强度都不受影响。兼容基线 Chrome 67+ / Safari 14+，旧机型（iOS 15.3-、老版微信 XWeb）也做了兜底。

### 📱 手机端不再"假装在线"

以前的心跳是单向的：电脑发、手机回，手机自己没有任何判活逻辑。于是**电脑休眠、拔网线、切 Wi-Fi、隧道被掐**这类情况——TCP 不会发 FIN/RST——界面会一直显示「已连接」，点发送也只是静默进缓冲，看着一切正常。

现在手机自己也探活：下行安静 **15 秒**发一帧 ping，**8 秒**没回补探一次，**连续两轮无回**才判死。两个细节值得说：

- **传文件期间全程暂停探活**。慢链路上一块的确认往返可能就超过 15 秒，探针会排在已发出去的数据后面，最后被自己的排队时间判死——那段时间的判活交给传输自己的确认机制
- **切回前台、切回网络时先探一帧再决定**。以前见到"连接还在"就直接返回，于是永远没有恢复路径，正好卡在"切回来看着已连接、其实发不出去"上

### ⚙️ 发送方式可以由电脑端统一下发了

**设置 → 手机端设置 → 发送方式**：默认 / 自动发送 / 手动发送。

- 手机连上后自动生效；改这个设置时，正在连着的那台也会**立刻跟着变**，不用重连
- 选 **默认** = 不下发偏好，手机端沿用自己当前的选择，电脑不干预（也不会覆盖你在手机上临时切的那一下）
- 手机端那颗 ⚡ 切换按钮照旧可用，只是属于临时改动

顺带把输入框为空时右下角的按钮从三横改成了 **加号（+）**，和微信一致，一眼看得出是「展开更多」而不是「菜单」。

> 小变化：「上屏方式」现在只保留在**主界面菜单**和**托盘右键**两处，设置窗口里那一项去掉了。三处本来就是同一个开关，留两处不损失功能，设置窗口也清爽些。

### 🐛 修掉的小毛病

- **微信浏览器不再弹"关闭网页"**：以前连点几次"重发"，微信的防骚扰策略会把确认框的「取消」改写成「关闭网页」，一碰就被带走。确认框现在改成页面内自绘的，不阻塞主线程、也不会被改写
- **长按消息回填后没有发送按钮**：长按一条历史消息回填到输入框，右下角还停在展开按钮上，现在会正常变成发送
- **点托盘后窗口不出来**：从托盘恢复主界面时，窗口有时被别的程序挡在后面（Windows 会直接忽略非前台线程的置前请求）。现在补了标准做法，点一下就真的到最前
- **第一次说话慢半拍**：悬浮窗首次显示要做一次性初始化（实测 400–600ms），这笔开销以前全落在你第一次说话时。现在启动后先在屏幕外预热一遍，首次显示从 **415ms 降到 4ms 左右**
- **审批面板的识别码会被顶掉**：以前来一条新请求就跳到队首，而那个 4 位数字你可能正低头核对——核对的和批准的不是同一条，这一步就白做了。现在队首永远是**排队最久**的那条，新连接排到后面等；手机刷新页面属于同 IP 重连，就地换个码、位置不动
- **启动与切换网卡快一点**：就绪探测的轮询间隔缩短，等服务器起来的时间少了

### 🛠 其他

- **「关于」窗口重做**：版本号与 commit 现在可以直接选中复制（反馈问题时附上这一行就够了），底部加了项目主页链接，点开即用浏览器打开
- **调试入口改为显式开关**：默认怎么运行都不会多出诊断入口。要看手机端现场（微信内置浏览器没有 devtools）时，用 `--debug` 或 `PHONEMIC_DEBUG=1` 启动才会出现日志浮层、`/test` 输入测试页和鼠标曲线调试——安装包同样支持 `PhoneMic.exe --debug`
- 修掉加密模式下 `/{secret}/test` 能绕过调试开关的漏洞（门禁下沉到路由内部）
- 依赖声明补入 noble 及其许可（`NOTICE.txt` / `NOTICE_en.txt`）
