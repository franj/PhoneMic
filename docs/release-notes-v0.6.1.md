## PhoneMic v0.6.1

这一版最大的两个变化，都是安全上的：

- **不让别人乱连**（防冒充）：新连接必须过一道认证，局域网下两种任选——**扫码认证**（密钥在二维码里，扫一下就连），或**人工认证**（扫码、手输网址都行，差别是要在主界面**点一次「允许」**确认是本人，就多这一步）。两种都加密、安全性没差别，只差在要不要确认。
- **不让别人偷看**（防窃听）：所有通信一律端到端加密、**取消明文模式**。起因是新增了文件传输——文件一旦明文，同网段的人抓包就能看到内容，索性全加密。

> 说明：上面防的是**同一网段里的偷看和冒充**。HTTP 谈不上绝对安全——理论上中间人能篡改手机加载的页面；但真碰上中间人的情况很少，家用、公司网络基本不用担心。外面的 WiFi 留意一下就行，风险最高的是无密码或共用密码的开放热点。想省心就用自己手机热点，或走 Cloudflare 模式（HTTPS）。

其余更新：上屏新增**模拟键盘（实时）**，说话时文字直接逐字落在光标处；安装包**不再需要管理员权限**。

### 🔑 两种连接方式：扫码认证 或 人工认证

两种方式都能连，**本质都是端到端加密、安全性没差别**，唯一区别是**连的时候要不要在电脑上确认一次**。两种扫码都能连，人工认证只是多一道确认：

- **扫码认证**：程序界面显示一张带 PC 公钥的二维码，扫一下就连上，电脑上不用操作。网址很长（密钥在里面），一般只能扫。
- **人工认证**：同样扫码就行，网址短、想手输也可以；差别是主界面会弹认证请求，你**点一次「允许」**即可。

自己用 NGINX 之类反代到公网域名的话，人工认证更顺手——这类部署谁都能访问到，现在加了这道认证反而更安全。

> 短网址看着简单，安全性却不打折：扫码认证方式的PC公钥直接摊在网址里，人工认证方式的密钥不可见、在PC程序界面当面确认，反而更难被旁人拿到。安全性都在同一档，选哪个就看你想不想多确认这一步。

人工认证流程：

1. 手机浏览器扫码或手动打开 `http://电脑IP:端口`（不带二维码参数）
2. 主界面出现认证请求，显示 **4 位识别码**与来源 IP
3. 核对手机屏幕与电脑上的识别码**一致** → 点「允许」

配对成功后手机会记住这台电脑：只要电脑端**没有重启程序、重启服务或切换模式**，此后重连就自动完成认证，不再需要审批。一旦发生上述任一操作，PhoneMic程序会换一套新身份，需要重新配对一次——手机会自动发起，你在程序界面上再点一次「允许」即可。

审批请求 30 秒未处理视为拒绝，重新连一次即可。

> **识别码对不上就点「拒绝」**——这一步防的是同局域网里别人抢先连上你的电脑。注意，公网（Cloudflare）模式强制扫码认证，不提供人工认证方式。

### 🔒 通信全程加密

以前局域网模式可以不加密，同一 WiFi 下抓包就能看到你输入的内容；**而本版新增了文件传输，一旦明文，传的文件内容同样会被窃听**，所以这次直接**取消明文模式**——所有模式一律端到端加密（密钥只存在于手机和电脑两端），中间节点看不到明文，文件也不会泄露。原有的"加密 / 不加密"配置会自动迁移，**无需手动调整**。

### ⌨️ 上屏方式新增「模拟键盘（实时）」

| 方式 | 什么时候用 |
| --- | --- |
| **剪贴板粘贴**（默认） | 长文本一次到位；一次粘贴在撤销栈里只算一步 |
| **模拟键盘输入** | 终端、SSH 客户端、vim 这类 Ctrl+V 不生效的程序 |
| **模拟键盘（实时）** | 想看着文字边说边出现 |

主界面菜单、托盘右键、设置窗口三处都能切，改一处其余同步，**即时生效、无需重启**。

选**实时**时留意两点：文字落在**开始说话那一刻**的光标位置，识别过程中别切窗口（焦点一变立即停手，后续内容改用悬浮窗）；它是逐字敲入的，配了 Ctrl+Z / Ctrl+Y 这类撤销命令时建议改用剪贴板粘贴。

### 📁 文件传输：进度与完成以电脑确认为准

以电脑实际收到并写盘为准，慢网络下不会再出现「手机已 99%、电脑才传了两成」。

### 🛠 底层改进

- Cloudflare 隧道定期自检维持可用；域名仍被回收时状态栏提示**隧道失效，请重启服务**，菜单 **网络 → 重启服务** 可重建隧道并分配新域名
- 握手增加一步密钥确认（挑战应答）：录下的旧认证报文原样重放也过不了
- 握手改为逐连接独立进行：认证失败的连接不会顶掉已连上的手机
- 修复：托盘右键「命令配置」报错、配置文件损坏后启动崩溃、退出残留 `.part` 半成品、大文件传输被心跳误判掉线、「记住上次网卡」有时不生效、实时输入在切模式或断连后静默退化成悬浮窗

### 📥 安装包不再需要管理员权限

安装位置改到用户目录，安装和卸载都**不再弹管理员权限确认**。装过旧版本（在系统目录）的话，安装程序会先自动清理，这一步请求一次权限，之后就不用了；卸载前会再确认一次，避免误点。
