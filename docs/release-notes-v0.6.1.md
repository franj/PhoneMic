## PhoneMic v0.6.1

这一版文字上屏多了**模拟键盘（实时）**，说话的时候文字就逐字落在光标处，不用等说完；文件传输的进度与结果改以电脑确认为准，手机显示和电脑实际写入对得上了；Cloudflare 隧道会定期自检以维持可用。安装包换了装法，**不再需要管理员权限**。

### ⌨️ 上屏方式三选一：新增「模拟键盘（实时）」

| 方式 | 什么时候好用 |
| --- | --- |
| **剪贴板粘贴**（默认） | 速度快，长文本一次到位，撤销时一步撤完整段 |
| **模拟键盘输入** | 终端、SSH 客户端、vim 这类 Ctrl+V 不生效的程序 |
| **模拟键盘输入（实时）** | 想看着文字边说边出现，像自己亲手敲的一样 |

三个入口都能切：主界面菜单栏的 **上屏方式**、托盘图标右键菜单、设置窗口里的 **上屏方式**。改一处其余立刻同步，**即时生效、无需重启**，当前选中的那种前面会标出圆点。

选**模拟键盘（实时）**时有两点要留意：

- 文字落在**开始说话那一刻**光标所在的位置，识别过程中别切换窗口、也别把光标点到别处。焦点一变，PhoneMic 会立刻停手，后面的内容改用悬浮窗显示，已经打出去的字留在原地。
- 它是逐字敲进去的，目标程序的撤销栈里记的就是这一串按键。想让一次 Ctrl+Z 撤掉**一整段**语音内容，用剪贴板粘贴——一次粘贴在撤销栈里只算一步。给语音命令配 Ctrl+Z / Ctrl+Y 这类撤销动作时尤其建议这样搭配。

### 📁 文件传输：进度与结果以电脑确认为准

传输进度不再由手机估算，而是以电脑实际收到的数据为准，显示完成前也会先等电脑确认文件已保存到位，慢网络下不会再出现「手机已 99%、电脑才传了两成」。

顺带修了一处误判：大文件传输时连接的心跳探测会被排在数据之后，慢网络下容易误判掉线、掐断正在进行的传输；心跳现在改为依据「最近一次收到对端消息」，数据仍在流动就不会误判。

### 🌐 Cloudflare 隧道稳定性提升

免费临时域名在长时间无访问时会被 Cloudflare 回收。PhoneMic 现在会定期访问隧道公网地址，维持链路活跃；若域名仍被回收，主界面状态栏会提示 **隧道失效，请重启服务**，通过顶部菜单 **网络 → 重启服务** 即可重建隧道并分配新域名。

### 📥 安装包不再需要管理员权限

安装位置改到用户目录，安装和卸载都**不再弹管理员权限确认**：

- 装过旧版本（在系统目录）的话，安装程序会先帮你清理掉它，这一步会请求一次管理员权限，之后就再也不用了
- 卸载前会先跟你确认一次，避免误点

### 🛠 底层改进

- 端到端加密的握手增加一步密钥确认（挑战应答）：即便有人录下上一次的认证报文原样重放，也过不了
- 新增 Referrer-Policy 响应头，页面地址不会在跳转时被带进第三方请求
- 修复托盘右键「命令配置」报错
- 修复配置文件损坏后启动崩溃
- 修复退出时残留 `.part` 半成品文件
- 修复「记住上次网卡」有时不生效
- 修复实时输入模式在切模式或断连后，静默退化成悬浮窗显示
