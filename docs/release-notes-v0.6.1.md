## PhoneMic v0.6.1

文字上屏又多了一种玩法：**模拟键盘（实时）**。选上它，说话的时候文字就像输入法一样逐字冒在光标处，不用等说完，也不用盯着悬浮窗看。它和语音命令也能配合：一句话命中了命令，PhoneMic 会先把识别过程中已经打出的字面文字撤掉，再执行命令。

### ⌨️ 上屏方式三选一

| 方式 | 什么时候好用 |
| --- | --- |
| **剪贴板粘贴**（默认） | 速度快，长文本一次到位，撤销时一步撤完整段 |
| **模拟键盘输入** | 终端、SSH 客户端、vim 这类 Ctrl+V 不生效的程序 |
| **模拟键盘输入（实时）** | 想看着文字边说边出现，像自己亲手敲的一样 |

三个入口都能切：主界面菜单栏的 **上屏方式**、托盘图标右键菜单、设置窗口里的 **上屏方式**。改一处其余立刻同步，**即时生效、无需重启**，当前选中的那种前面会标出圆点。

选**模拟键盘（实时）**时有两点要留意：

- 文字落在**开始说话那一刻**光标所在的位置，识别过程中别切换窗口、也别把光标点到别处。焦点一变，PhoneMic 会立刻停手，后面的内容改用悬浮窗显示，已经打出去的字留在原地。
- 它是逐字敲进去的，目标程序的撤销栈里记的就是这一串按键。想让一次 Ctrl+Z 撤掉**一整段**语音内容，用剪贴板粘贴——一次粘贴在撤销栈里只算一步。给语音命令配 Ctrl+Z / Ctrl+Y 这类撤销动作时尤其建议这样搭配。

### 🛠 配合语音命令

实时模式下，识别过程中的文字已经打进文档了。要是这句话正好命中一条命令，PhoneMic 会先把这些文字撤掉，再执行动作：

- 说「回车」触发换行命令，文档里不会多出"回车"两个字，只有那次换行。
- 说一句带 `{content}` 模板的命令，撤掉之后由命令自己输出该有的内容。

顺序是**先撤、后执行**——命令往往只是一个回车或一组快捷键，字面文字带着就多余了。
